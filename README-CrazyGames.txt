WOBBLE CUP - CrazyGames build
==============================

UPLOAD
- Upload this ZIP with index.html at the root.
- Keep the avatars/ folder next to index.html.
- The game includes the World Cup cinematic intro, match intros, profile pictures, username-based friends, and online room play.

ONLINE / SOCIAL
- Online rooms still use the existing 4-digit room code for match connection.
- Profile/Friends now use usernames instead of friend codes.
- Usernames use letters, numbers and underscore and are stored locally on the device.
- The game prevents duplicate usernames on the same device.
- IMPORTANT: true permanent global username reservation across every device requires a server/database; this build does not pretend localStorage can provide that.

WORLD CUP / MATCH INTRO
- The cinematic intro appears before every normal match.
- Every World Cup match also uses the cinematic intro.
- World Cup champion wins keep the trophy/fireworks victory transition.
